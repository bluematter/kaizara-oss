# Security

Report security issues privately through [Report a vulnerability](https://github.com/bluematter/kaizara-oss/security/advisories/new) on this repo. Do not post them in public issues.

Describe the affected code and how to reproduce the issue with invented data. Never include patient data in a report. Remove passwords, tokens and other secrets from logs or attachments.

Responses and fixes are best effort. There is no guaranteed response time and no bug bounty.
